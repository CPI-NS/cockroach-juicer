# Result-analysis boundaries

Research exports preserve source, environment and repeat identity. Capacity-wait
diagnostics feed working-point validity through `diagnostics.capacity_limited`.
Interpret only the measurement population recorded by the native client;
warmup-inclusive counters are not measurement-window counts.

Use the public evaluation entry and common plotting renderer. Check complete
process coverage, native exits, verified collection and the selected measurement
window before combining cells. See [EVALUATION.md](EVALUATION.md),
[EVALUATION-COVERAGE.md](EVALUATION-COVERAGE.md) and
[VALIDATION.md](VALIDATION.md) for the maintained interfaces and checks.
